# Дневник здоровья — PWA

Приложение для телефона (Android/iPhone), которое устанавливается по ссылке как настоящее приложение.

## Как это работает

1. Загрузите все файлы этой папки в репозиторий на GitHub
2. Включите GitHub Pages (Settings → Pages → Source: main)
3. Получите ссылку вида `https://ваш-логин.github.io/название-репо`
4. На телефоне откройте ссылку → браузер предложит «Добавить на главный экран»
5. Приложение установится как обычное приложение с иконкой на рабочем столе

## Файлы

- `index.html` — основной файл приложения
- `manifest.json` — конфигурация PWA (устанавливаемость)
- `service-worker.js` — работает без интернета (кэширование)
- `icon.svg` — иконка приложения

## Возможности

- Запись давления правой/левой руки (верхнее/нижнее)
- Запись веса и роста
- Запись пульса (уд/мин) с проверкой диапазона
- Автоматический расчёт ИМТ (вес ÷ рост²)
- Выбор даты и времени записи (по умолчанию — текущие)
- Время записи фиксируется автоматически и показывается в истории
- История записей по дням и месяцам
- Давление и пульс в истории показаны отдельно по рукам: сверху правая (П), снизу левая (Л)
- Графики давления, пульса, веса, ИМТ за 7/30/90 дней и всё время
- Автобэкап раз в неделю в память телефона
- Экспорт/импорт данных в JSON

## Как добавить на главный экран

### Android (Chrome):
1. Откройте ссылку в Chrome
2. Меню ⋮ (три точки)
3. «Добавить на главный экран»
4. Подтвердите установку

### iPhone (Safari):
1. Откройте ссылку в Safari
2. Кнопка «Поделиться» (квадрат со стрелкой)
3. «На экран «Домой»»
4. Подтвердите

## Важно

При первом открытии нужна интернет-связь для загрузки библиотек (Tailwind, Chart.js). После этого приложение кэшируется и работает без сети. Все данные хранятся локально в браузере телефона.
